# Post 8 — 2026-07-14 — explainer reel
**Angle:** MCP becoming the standard across ServiceNow, Salesforce, and Oracle made cross-platform agents easy and expanded the attack surface at the same time.

## Caption
MCP won the protocol war this year. That decision quietly handed external agents a doorway into your workflow runtime, your CRM records, and your analytics. The connection got easier. So did the reach of anything you connect.

## Copy

Frame 1:
This year MCP became the standard connector across ServiceNow, Salesforce, and Oracle. Cross-platform agents got easy overnight.

Frame 2:
ServiceNow Action Fabric opens the workflow runtime to outside agents through a GA MCP server, shipped in every Now Assist SKU.

Frame 3:
Salesforce went the same way. Hosted MCP servers expose SObject records, Data 360 queries, and Tableau to Claude, ChatGPT, and Cursor.

Frame 4:
Every one of those doorways is now something an external agent can reach. The easy connection and the wider attack surface are the same decision.

Frame 5:
Traditional IAM and RBAC were built for people and standing services. They cannot keep pace with short-lived agents spinning across hundreds of services.

Frame 6:
So the open question is no longer which protocol wins. It is how you secure the MCP servers you already turned on.

Frame 7:
Secure your MCP surface now. Get in touch.
