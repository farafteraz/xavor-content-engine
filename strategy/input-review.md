# Input review and agreed correction

Reviewed September 30, 2026. This records an inspection of the archived August
corpus and Sentinel's existing code, not a fresh market survey.

## Findings

The August corpus includes repeated discussion of Agentforce pricing, AI cost
attribution, data semantics, and physical-AI integration across weekly digests.
It also contains proposed content titles, Xavor positioning instructions, and
suggested offerings. One example proposes a six-week AI FinOps service; that
proposal is not evidence Xavor offers or has delivered it.

The inspected Sentinel prompt targeted Fortune 500 readers, required per-signal
content ideas, asked for at least three items in qualifying sections, and always
requested five calendar ideas. Its run had no prior-digest input. Those are
confirmed design constraints. Their contribution to repetition is a reasonable
inference; no quantitative causal test has been performed.

The first opportunity runner compounded this by requiring a corpus citation,
technical alternatives, and resolution of every listed unknown for each idea.
That imposed a news-led technical assessment on content regardless of format.

## Corrections

The content engine now accepts commercial direction, buyer context, Xavor
experience, and competitive observations as starting points alongside external
signals. News hooks and technical comparisons are optional. Confirmed context is
separate from editorial hypotheses. The review distinguishes blocking central
problems, writer notes, and context; only the first prevents recommendation.

Sentinel's companion change adds recent-digest memory, broader research sources,
and a competitive-content section studying both messaging and execution. It
removes forced calendar suggestions and minimum counts. The research should
identify differences from previous coverage rather than repeat launches with a
new headline. The memory is bounded and novelty judgment remains model-based.

The user named Tkxel, Systems Limited, and Devsinc as initial peers and specified
that the references should sell services. The reference set therefore also
includes specialist examples from Razorleaf, Coastal, and INRY. Recruitment and
company celebrations are not useful service-selling examples. An event recap
can qualify when it explains a service and provides a relevant demonstration.
See `knowledge/competitive-context.yml` for actual observed examples and URLs.

## Remaining gaps

The public sample is small, sometimes historical, and mostly caption text.
It does not establish cadence, visual quality, conversions, or sector-wide norms.
No useful Devsinc service-selling example was verified in the initial search.
No new practitioner interviews or cross-account objection inventory have been
collected. Case-derived questions remain hypotheses. No new generation run has
proved that these revisions improve final content.

The existing August artifacts remain unchanged. October planning should use
September research; the comparison command still explicitly supports August.
